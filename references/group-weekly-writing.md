# 组周报概述与图片标准

适用于“出行与生态产品组周报 → 生态数据”的管理层摘要。完整分析文档仍保留必要的数据来源和计算说明；本页只规范组周报概述与两张摘要图。每期先看现行 SOP 和上期已发布章节；若有明确更新，以最新要求为准。

## 写作顺序与重点

1. **总**：首句突出加粗的原生应用整体使用占比，写本周值和环比 pp；仅在有明确目标值时补充目标差距。接着说明音频、视频总盘需求的车辆渗透率变化，定性判断后立即给出括号内证据，格式为“音频由上周 A% 升至本周 B%，+C pp；视频由上周 D% 升至本周 E%，+F pp”。再概括原生占比改善主要来自哪一类业务，并在括号内给出两类的 pp 变化。
2. **分 1. 音频、2. 视频**：每项开头加粗该业务的**原生占比本周值**，紧接环比。解释时优先描述非原生来源的变化趋势及其与原生占比目标的关系；业务总盘车辆渗透率是需求覆盖变化的主指标。少量应用 UV 增幅可作为证据，避免逐项罗列绝对 UV。
3. 每个可核实的定性判断后紧跟括号内数据，至少说明两期值、pp 变化，或应用增幅与同口径总盘增幅的比较。例如：“非原生来源仍增长（蓝牙 UV +A%、商店音乐 UV +B%）”。没有可核实数字就不写成事实；可能原因标为“可能”或“待验证”，并指出核验所需数据。

## 表达边界

- 黑体优先用于整体、音频、视频的原生占比；不要让车辆渗透率、单应用 UV 或推测抢过核心目标的视觉重点。
- 概述分析非原生来源的现状和变化，不把“非原生缺口”当成标题或主结论。
- 管理层概述不附“口径说明”段，也不在结论中解释公式。完整分析文档与工作底稿保留可追溯的计算定义。
- 应用可跨渠道、跨音源重叠；单项变化不能直接归因为原生占比变化，也不能把相关性写成产品动作的已证实效果。
- 占比和车辆渗透率变化用 pp，UV 相对变化用 %；上期与本期必须采用同口径、同过滤条件和可比较的数据快照。

## 两张摘要图

1. 先查看上期**实际发布的图片**，再确定本期画布比例、分栏、颜色、字体层级、图例和行序。第一张承载总体原生占比、音频/视频结构及关键非原生来源；第二张按音频、视频分区展示来源变化。图表可随本期数据增减行数，但读者应能沿用上周的阅读路径。
2. 图片中的定性标题或结论也应能在邻近位置看到比较值。占比、车辆渗透率和 UV 不能混标；颜色只表达同一套稳定的类别或周别。
3. 生成后目视检查两张图的文字、数值、留白、边界和上周样式的差异。若使用者要求先审稿，把新图放入独立预览文档供检查，确认前不改正式组周报。
