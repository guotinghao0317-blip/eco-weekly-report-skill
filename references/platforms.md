# 在不同工具中导入

本仓库只有一份核心 `SKILL.md`，不按工具复制业务口径。各工具的导入按钮和版本可能变化，以下入口在 2026 年 10 月按官方资料核对；以当前客户端界面为准。

| 工具 | 导入方式 | 完整执行前的检查 |
| --- | --- | --- |
| WorkBuddy | 在技能管理界面导入本地技能包，或按客户端提供的 GitHub/技能安装入口加载。参见 [官方技能说明](https://cloud.tencent.com/document/product/1831/134432)。 | 能否运行本地终端、读取工作目录、访问飞书 CLI、显示授权链接与图表。 |
| 豆包工作桌面版 | 在“技能·连接器·伙伴”中导入本地技能文件。参见[飞书对豆包工作的介绍](https://www.feishu.cn/content/article/7677519271848610746)。 | 同左；若工具内置飞书能力与 CLI 能力不同，仍需满足同样的读写和核验结果。 |
| Codex 等支持 `SKILL.md` 的工具 | 将整个技能文件夹放入该工具的技能目录，或让工具读取 `SKILL.md`。 | 本地终端、Python 3、飞书 CLI 可用。 |

普通豆包聊天端没有经过本仓库的本地 CLI 执行验证，不能将“能阅读技能说明”当成“能自动完成飞书写入”。具体平台应先用虚构示例做一次读取、终端、图片与回读测试；遇到能力缺失时说明并停在可人工接手的产物。

工具导入后建议用一句话测试：

> 请加载“生态业务数据周报”技能，先检查飞书 CLI 与授权状态，再使用虚构示例生成本地指标和七张图；不要向飞书发消息或写文档。
