# 数据口径与交付检查

本文件整理本组 2026 年 10 月周度 SOP 中影响计算的规则。每期先读取现行 SOP；若它已修改，以现行文本为准，记录变更，不悄悄沿用旧口径。

## 周期与来源

- 本期为周四至次周三的 7 天，对比期为紧邻的前 7 天。两期采用同样的正式交付车和版本过滤；不要把无数据的版本写成已覆盖。
- 北极星三指标优先取业务方在生态数据群发布的看板截图。若用 BI 重算，应记录截图与重算时间、差异及采用哪一组值。
- 应用级明细、音频总盘去重 UV、视频总盘去重 UV、上电车辆数可向有权访问的 BI 数据源取得。先查现有群回数；问机器人时写清周期、对比期、车辆/版本过滤、指标、维度、去重单位与所需原始明细。
- 使用者确认每条向群发送的完整消息后才能发送。已有明确回数时不要重复提问。
- 记录原始截图/附件的消息 ID、取数时间和查询过滤。不得把不同取数时点的数字默认为同一快照。

## 必须区分的算法

| 指标 | 算法 | 使用位置 |
| --- | --- | --- |
| 北极星周值 | 每日业务占比的 7 天算术平均 | 北极星表、组周报指标总表 |
| 应用拆解占比 | 应用周日均去重 UV ÷ 对应业务总盘周日均去重 UV | 拆解表、占比图 |
| 音频/视频车辆渗透率 | 对应业务总盘周日均去重 UV ÷ 同期上电车辆周日均去重 UV | 组周报概述、需求覆盖变化 |
| 单应用车辆渗透率 | 应用周日均去重 UV ÷ 同期上电车辆周日均去重 UV | 渗透率图、运营明细 |
| UV 环比 | 本期 UV ÷ 对比期 UV − 1 | 应用趋势、榜单 |
| 占比/渗透率变化 | 本期百分比 − 对比期百分比 | 以 pp（百分点）表示 |

音频原生包括 QQ 音乐、网易云音乐、酷狗的 SDK，需用去重并集；音频总盘覆盖原生、商店、X-Pad/浏览器、蓝牙、USB 等实际音频需求，亦须跨源去重。视频北极星是商店视频应用对视频需求总盘的满足占比；视频总盘覆盖商店、X-Pad、浏览器视频需求。单个应用的 UV 可以重叠，不能将应用行相加得出总盘。

“原生占比”是目标指标，按对应北极星定义计算；排查问题时重点观察非原生来源的份额和趋势。音频/视频车辆渗透率描述该业务需求覆盖上电车辆的比例，不能以单应用渗透率或 UV 绝对增长代替。组周报同时写明渗透率的上周值、本周值与 pp 变化；单应用 UV 仅保留能支撑趋势判断的少量例子。

## 取数与核验

1. 先核对两期日期每天都有分区。若分区晚到，明确本期当前是几天数据，并等待补齐后更新图表。
2. 对照北极星分子/分母、应用明细和总盘分母的正式交付车、CDU 版本、日期、UV 去重粒度。缺任一分母时不计算对应占比或渗透率。
3. 对同一应用多个包名，优先按**每日用户/车辆位图并集去重**后再取周日均；不可把多个包名周均 UV 直接相加。
4. X-Pad 排除系统组件；浏览器排除内部壁纸/运营域名。其它榜单范围参照现行 SOP、上期榜单和实际包名清单。若只能从上期榜单推断某个排除规则，必须标注推断，并保留原始前 15 名供复核。
5. 上期已发布数与当前 BI 重算不同，先检查过滤、数据回刷和取值时点。无法证实原因时披露差异；环比两端使用同一快照，不混算。
6. 对比期若有假期、重大版本发布或其它特殊事件，在趋势解释中写明。结论必须有数字支撑；不得把相关性写成确定因果。

`scripts/prepare_report.py` 只处理已核实的标准输入，并不负责从飞书自动抓取或判断某个包名属于音频/视频。这些业务判断要留有来源和说明。

## 两份交付

**完整版**：本期 H1 放文档顶部；包含概述与行动建议、音频和视频北极星/拆解、7 张图、X-Pad 与浏览器 TOP10、口径说明和数据来源。图的规定顺序：音频 UV 占比、音频车辆渗透率、音乐各音源运营明细、视频 APP UV 占比、视频 APP 车辆渗透率、X-Pad TOP10、浏览器 TOP10。历史 SOP 建议蓝色 `#3370ff`、涨绿 `#1a9c48`、跌红 `#d32f2f`，表头、统计说明、数据表及趋势总结；脚本使用这些基本元素。若现行 SOP 的版式更具体，按现行版式调整。

**组周报**：在本期 M月W周 → 二、生态业务 → 0. 生态数据更新 7 列指标总表、概述和两张摘要图（综合对比、各子应用占比变化）。概述遵循 [总分结构与写作标准](group-weekly-writing.md)；两张图对照上期已发布原图的版式和信息层级制作。完整周报链接放入诊断行。月分成收入、原生音乐使用步长、应用上车成本等独立数据源缺数时写“待业务方更新”，不沿用旧值或编造。

**回读核验**：两份文档的本期章节存在且无重复；日期、过滤、北极星三指标、音频/视频总盘车辆渗透率、分母、图片数量与链接正确；缺数和口径差异有说明。组周报的定性判断有紧邻的数据括号，原生占比是加粗重点。保存本地标准输入、计算结果和来源清单，供下期复核。
